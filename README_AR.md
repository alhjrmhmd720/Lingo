# LINGO!!!! — Android Prototype

هذا مشروع Android حقيقي، وليس صفحة ويب مستقلة. التطبيق يحتوي على واجهة LINGO!!!! التجريبية داخل WebView، مع دروس عربية/إنجليزية واختبارات وأزرار تنقل تفاعلية.

## البناء

يتطلب Android Studio أو بيئة Android SDK حديثة مع JDK 17+.

افتح المجلد في Android Studio ثم اختر **Build > Build APK(s)**.

الناتج سيكون APK للتثبيت على هاتف Android.
