# LINGO!!!! — بناء APK من الهاتف

هذا المشروع مجهز ليُبنى تلقائيًا بواسطة GitHub Actions، بحيث لا تحتاج إلى كمبيوتر أو Android Studio.

## ما الذي يحدث؟
بعد رفع ملفات المشروع إلى مستودع GitHub على فرع `main`، سيبدأ GitHub Actions ببناء `app-debug.apk` تلقائيًا. GitHub Actions توفر أجهزة افتراضية لتشغيل عمليات البناء والاختبار.

## ما الذي يجب فعله على الهاتف؟
1. فك ضغط المشروع.
2. أنشئ مستودعًا جديدًا على GitHub.
3. ارفع **محتويات مجلد LINGO_Android** إلى جذر المستودع، وليس المجلد نفسه داخل مجلد آخر.
4. افتح تبويب **Actions** في المستودع وانتظر انتهاء مهمة **Build LINGO APK**.
5. افتح نتيجة التشغيل، ثم قسم **Artifacts**، وحمّل `LINGO-debug-apk`.
6. فك ضغط ملف الـArtifact وستجد `app-debug.apk`.
7. ثبّته على هاتف Android.
